# Restore v0.5.2 — 통합 설치·상태·보관 안정화

v0.5.1 이후 실제 변경 소스의 패치 릴리스입니다.

- 보호 폴더 설정과 초기 복구 상태 점검, 설치/제거용 수집 drain 및 상태 보고를 추가했습니다.
- 수집 DB 트랜잭션, 상태 전달, 보관 및 스냅샷 정리 경로의 안정화 변경을 포함합니다. 복구·검토 중 자료를 완료 자료로 취급하지 않습니다.
- JEV 키 보관 브리지의 관리자 ACL 및 키 검사 기능을 포함합니다. 실제 API 키는 포함하지 않습니다.
- 설치용 launcher와 주기 작업 연결 변경을 포함합니다.

통합 EXE: https://github.com/ransomguard/installer/releases/tag/v0.6.0-preview.3
대응 커널 소스: https://github.com/ransomguard/Kernel/tree/main/v0.9.1

preview.3는 이 변경 코드에 해당하는 백엔드를 포함하지만 내장 pyproject 버전은 0.5.1로 남아 있습니다. 이번 소스 배포에서 0.5.2로 바로잡았으며, 이미 게시한 EXE 파일을 조용히 교체하지 않습니다.

검증: 이 패키지의 전체 단위 시험 결과는 VALIDATION_PATCH.json에 기록합니다. 새 Windows 11 VM에서의 설치·재부팅·복구·제거 검증은 미완료입니다. 실제 JEV 오탐/미탐 성능을 검증했다고 주장하지 않습니다. UI 디자인과 기존 UI/방화벽 저장소는 이번 소스 게시로 변경하지 않습니다.

스냅샷 기본 보관 정책은 최대 12개·24시간·8GiB, 최소 2개 유지입니다. 복구/검토 hold 등 보호 대상은 제한 초과 상태에서도 임의 삭제하지 않으며, 용량 제한은 디스크 사용량에 대한 강제 절대 상한이 아닙니다.
