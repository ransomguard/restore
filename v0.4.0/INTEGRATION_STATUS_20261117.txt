2026-11-17 통합 검증 스냅샷
이 소스는 중간 점검용이며 제품 완성/운영 배포를 의미하지 않습니다.
실제 외부 JEV 호출은 검증에서 제외했습니다. Windows VM은 네트워크 연결 해제 상태로 검증했습니다.
시험용 탐지/복구 기록을 실제 악성코드 대응 실적으로 사용하지 않습니다.
현재 상시 실행 구성은 observe-only이며 전체 자동 대응이 기본 활성화된 상태가 아닙니다.
최신 방화벽을 포함한 전체 A/B 정책 해제까지의 재검증, WFP 실제 패킷 검증, 장시간 안정성 검증은 남아 있습니다.
기존 문서는 작성 당시 상태를 설명하므로 본 날짜의 통합 검증 결과와 구분해 읽어야 합니다.

VM 전체 240개 테스트가 통과한 복구 v0.4.0 소스와 Windows 문제 수정본입니다.
VSS 복구, JEV 클라이언트, Track A/B 세대 확인, 방화벽 정책 소유권/예외 방향,
영속 UI 전달, 원본 보존/자동 정리, SQLite 용량 카운터, 수집 버퍼/감시를 포함합니다.
integration/windows는 기존 실험용 설치 경로 C:\RG_Test를 사용하는 시작/관찰기 감시 스크립트입니다.
기존 설치 폴더와 RansomGuard-InteractiveStartup 작업이 준비된 VM용이며 범용 설치 프로그램이 아닙니다.
VMware 명령 에이전트, 호스트 제어 도구, VM 암호, API 키, 실제 DB/로그는 포함하지 않았습니다.
Python 패키지는 pyproject.toml 기준으로 설치하고 python -m unittest discover -s tests로 단위 검증할 수 있습니다.
