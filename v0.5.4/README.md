# Restore v0.5.4

격리 IP 예외 보존, 콘솔 경로 캐시, 주기 변경 잠금 대기와 TestLab 연계 수정본입니다. 이전 버전 폴더는 보존합니다.

# Ransom0 Preview19 — 온라인 전수 점검 및 수정본

- **설치:** [Ransom0-Install.zip](https://github.com/ransomguard/installer/releases/download/v0.6.0-preview.19/Ransom0-Install.zip) — 통합 EXE, 점검 도구, VM/호스트 시험 가이드.
- **시험:** [Ransom0-TestLab.zip](https://github.com/ransomguard/installer/releases/download/v0.6.0-preview.19/Ransom0-TestLab.zip) — 실행 도구, 사용법, 검증표.

두 ZIP은 용도별 묶음입니다. 설치에 다른 저장소나 Source code ZIP은 필요 없습니다. 내부 시험 서명판이며 Microsoft 정식 배포 서명·정식 altitude는 미확보입니다. API 키와 보호 폴더는 설치 후 설정합니다. 평상시 인터넷을 유지하고 위협 대응 시 격리합니다.

## 포함된 변경
- 격리 중 사용자가 등록한 IP 허용 목록을 JEV 예외와 함께 유지합니다.
- 자체 이벤트 수집 설정 ACK, UI 중복 실행 방지 및 IPC 재연결을 수정했습니다.
- 콘솔 스트림 경로 계산을 캐시하여 반복 경로 조회를 줄였습니다.
- 스냅샷 주기 변경의 범위 잠금 대기와 초기 UI 선택 덮어쓰기 문제를 수정했습니다.
- TestLab의 상태 참조와 부하 후 카운터 확인을 보강했습니다. Rule1001 Track A 표시와 파일 1개 보호 범위 수정도 포함됩니다.

## 검증 결과와 남은 문제
**80개 항목 중 통과 50, 부분 검증 10, 실패 1, 실패/미확정 1, 미검증 18입니다. 전체 통과판이 아닙니다.**

온라인 Windows 11 VM에서 실제 Track A 및 실제 JEV Track B의 강제 종료·VSS 복구·파일 해시 일치, IP 예외 통신과 차단, 프로그램 경로+해시 예외, 수동 스냅샷·복구를 확인했습니다. TestLab 1·2·4~11은 통과했으나 3번 12만 회 쓰기는 추가 유실 40,355건으로 실패했습니다. 누적 유실 1,162,915건을 초기화하지 않았습니다. Windows 업데이트 부하에서도 유실이 관측되어 병목이 완전히 해결된 상태가 아닙니다.

최종 주기 버튼 4개 재시험, 네이티브 선택창/일부 콘솔 X 닫기/용량 압박 삭제 등은 미완료입니다. UI 업데이트 latest.yml 404 및 JEV 관리 상태의 이전 Windows 방화벽 규칙 조회도 남아 있습니다.

VM 결과는 preview.18에 수정본을 적용한 기록입니다. **이번 preview.19 ZIP 자체의 신규 설치·재부팅은 미검증입니다.** 물리 PC 및 타 백신 공존도 검증 완료로 표시하지 않습니다. 로컬 백엔드 526·설치기 19·TestLab 11·UI 45개 시험과 UI lint/빌드가 통과했습니다.

각 ZIP의 검증결과.txt, checklist.csv와 SHA256SUMS.txt를 확인하세요. 원본 VM 자료·계정 키·진단 에이전트는 배포하지 않습니다.

## 복구 시험 순서
TestLab 6번으로 전용 문서 12개를 만들고 표시된 폴더를 설정의 복구 범위로 적용한 뒤 7·8·9번을 실행합니다. 12개는 시험 자료 개수이며 제품은 파일 1개도 지원합니다. 9번은 실제 JEV 요청이 발생합니다. 사용자 문서 폴더에서 시험하지 마세요.

소스 빌드 레시피는 기존 payload 및 드라이버 바이너리가 필요한 제작 환경용입니다. 저장소 하나만으로 완전 재현 가능한 빌드라고 주장하지 않습니다. 포함 파일은 payload-manifest.json으로 식별합니다.
